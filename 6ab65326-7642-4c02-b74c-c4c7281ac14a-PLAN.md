# Auth

- **Heslá:** PBKDF2, Web Crypto API, 600 000 iterácií, SHA-256, random salt 32 bytes
- **JWT:** HS256, expirácia 24h, uložený v **httpOnly cookie** — nie localStorage
- **apiFetch:** `credentials: "include"` na každom requeste, pri 401 redirect na `/login`

```ts
// frontend/utils/api.ts
export async function apiFetch(path: string, options?: RequestInit) {
  const res = await fetch(path, {
    ...options,
    credentials: 'include',
    headers: { 'Content-Type': 'application/json', ...options?.headers },
  })
  if (res.status === 401) window.location.href = '/login'
  return res
}
```

# Bezpečnosť

1. Secrets nikdy v kóde — `bunx wrangler secret put NAZOV`
2. Heslá: PBKDF2 — nikdy plaintext
3. JWT v httpOnly cookie — nie localStorage
4. Nikdy `git add .` — vždy konkrétne súbory
5. SQL cez Drizzle ORM alebo `.bind()` — nikdy string interpolácia
6. Errors: nikdy nevráť stack trace užívateľovi
