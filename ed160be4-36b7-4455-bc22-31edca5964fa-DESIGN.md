# ⚡ Wizarding UI Design System
*Harry Potter–inspired design language — built on Tailwind v4*

---

## Stack

- **Tailwind CSS v4** — utility-first, CSS-variable driven
- **Vite** (or any bundler)
- **Fonts** — Google Fonts (Cinzel, IM Fell English, Cormorant Garamond)

---

## Setup

### `app.css` — Theme Definition

Tailwind v4 uses `@theme` instead of `tailwind.config.js`.

```css
@import "tailwindcss";

@import url('https://fonts.googleapis.com/css2?family=Cinzel+Decorative:wght@400;700;900&family=Cinzel:wght@400;600;700&family=IM+Fell+English:ital@0;1&family=Cormorant+Garamond:ital,wght@0,300;0,400;0,600;1,300;1,400&display=swap');

@theme {
  /* === FONTS === */
  --font-display:  'Cinzel Decorative', serif;
  --font-heading:  'Cinzel', serif;
  --font-body:     'IM Fell English', Georgia, serif;
  --font-ui:       'Cormorant Garamond', serif;

  /* === COLORS === */
  --color-void:          #0a0608;
  --color-obsidian:      #110d10;
  --color-stone:         #1c1620;
  --color-dungeon:       #241d28;
  --color-parchment:     #f4ead5;
  --color-aged:          #e8d9b5;

  --color-gold-dim:      #7a5c1e;
  --color-gold:          #c9972a;
  --color-gold-bright:   #f0c040;
  --color-gold-glow:     #ffd700;

  --color-crimson:       #8b1a1a;
  --color-crimson-bright:#c0392b;
  --color-cobalt:        #0f2d5e;
  --color-cobalt-bright: #1a4a9c;
  --color-emerald:       #0a3d1f;
  --color-emerald-bright:#1a6b3a;

  --color-magic:         #4fc3f7;
  --color-fire:          #ff6b00;

  --color-text-primary:  #f4ead5;
  --color-text-secondary:#b8a98a;
  --color-text-muted:    #7a6a52;
  --color-text-accent:   #f0c040;

  --color-border:        rgba(201,151,42,0.25);
  --color-border-bright: rgba(201,151,42,0.6);
  --color-border-dim:    rgba(201,151,42,0.1);

  /* === SHADOWS === */
  --shadow-gold:       0 0 8px rgba(201,151,42,0.4), 0 0 24px rgba(201,151,42,0.2), 0 0 60px rgba(201,151,42,0.08);
  --shadow-gold-hover: 0 0 12px rgba(201,151,42,0.6), 0 0 40px rgba(201,151,42,0.3), 0 0 80px rgba(201,151,42,0.12);
  --shadow-card:       0 8px 32px rgba(0,0,0,0.4);

  /* === ANIMATIONS === */
  --animate-unfurl: unfurl 0.7s cubic-bezier(0.22,1,0.36,1) both;
  --animate-flicker: flicker 4s ease-in-out infinite;
  --animate-float:   float 6s ease-in-out infinite;
}

@keyframes unfurl {
  from { opacity: 0; transform: translateY(16px) scale(0.98); filter: blur(4px); }
  to   { opacity: 1; transform: translateY(0) scale(1); filter: blur(0); }
}

@keyframes flicker {
  0%, 100% { opacity: 1; }
  50%       { opacity: 0.85; }
  75%       { opacity: 0.95; }
}

@keyframes float {
  0%, 100% { transform: translateY(0); }
  50%       { transform: translateY(-8px); }
}

body {
  @apply bg-void text-text-primary font-body;
  background-image:
    radial-gradient(ellipse at 20% 50%, rgba(201,151,42,0.03) 0%, transparent 60%),
    radial-gradient(ellipse at 80% 20%, rgba(139,26,26,0.04) 0%, transparent 50%);
}
```

## Motion Utilities

Add to `app.css`:

```css
.reveal   { animation: var(--animate-unfurl); }
.reveal-1 { animation-delay: 0ms; }
.reveal-2 { animation-delay: 80ms; }
.reveal-3 { animation-delay: 160ms; }
.reveal-4 { animation-delay: 240ms; }
.reveal-5 { animation-delay: 320ms; }

.float   { animation: var(--animate-float); }
.flicker { animation: var(--animate-flicker); }
```

## Design Rules

| Rule | Value |
|------|-------|
| Border radius | `4px` cards · `3px` buttons/inputs · `2px` badges |
| Gold glow | On hover — buttons, cards, active links |
| Fonts in UI | Always serif — never system/sans |
| Parchment bg | Forms, modals, doc contexts only |
| Animations | Page-load stagger + hover only — no decorative loops on interactive elements |
| Dark base | `#0a0608` — near-black, never pure `#000` |
